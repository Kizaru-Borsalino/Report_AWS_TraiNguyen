## Sharing

Through this project, the team practiced a development process close to a real environment: identifying the problem, proposing a solution, designing the architecture, developing backend/frontend, testing, and deploying to AWS.

The most valuable part of the project was connecting programming knowledge with cloud services. Services such as EC2, RDS, S3, IAM, and CloudWatch were not only deployment components; they also directly affected how the application was designed, how files were stored, how data was protected, and how the system was operated.

## Feedback

- More time should be allocated for end-to-end deployment on a real domain.
- CI/CD should be added to automate frontend/backend build and deployment.
- The project could be extended with email notifications, skill-based job matching, and a more advanced admin dashboard.
- For production deployment, HTTPS, backup strategy, alerting, and deeper security testing should be added.
