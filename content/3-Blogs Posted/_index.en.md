This section presents the **three technical blog posts** I published in the AWS Study Group community as part of my internship learning journey. Each article connects what I learned from the JobGo project with broader AWS topics such as application security, secure development practices, and AI application architecture.

### Blog list

1. [Building Secure Applications from the Design Stage with AWS Security Agent](3.1-Blog1/)
Summary: This post explains why security should start at the architecture phase and how AWS Security Agent can support threat modeling and early design review for the JobGo platform.

2. [AI Code Review with AWS Security Agent: Detecting Security Gaps Before Deployment](3.2-Blog2/)
Summary: This post focuses on how AI-assisted code review helps identify security weaknesses in key APIs such as login, CV upload, and job-post management before code reaches production.

3. [Building AI Applications on AWS: What Do Developers Actually Need?](3.3-Blog3/)
Summary: This post provides a practical roadmap for building real AI applications on AWS, covering foundation models, RAG, Amazon Bedrock, and production concerns such as security, monitoring, and cost control.

### Why these posts matter

Together, these three articles helped me organize my internship learning into three connected themes:

- Security by design.
- Security during implementation and review.
- End-to-end AI application thinking on AWS.

Writing these posts also improved my ability to explain technical ideas clearly, connect theory with practice, and communicate project experience to a wider community.
